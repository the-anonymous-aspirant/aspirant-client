- **Invoices: the N26 import names the transfers from PayPal it left out**
  (system_3 #9890, from #9881). The server leaves out an N26 credit whose
  payer is PayPal, because its payments come in through the PayPal import
  (aspirant-server PR 158). Each file in the review dialog now says how many
  it left out ("2 transfers from PayPal left out: their payments come in
  through your PayPal import."). For a file with no other row, that line
  replaces "No incoming payments in this file.", and the footer reads
  "Nothing to import: every payment read is a transfer from PayPal." when
  nothing else was read. The N26 summary card adds the count after
  "skipped", and its "read N rows" includes it, so the line adds up on
  import and on cancel. A response without the count renders as before.
