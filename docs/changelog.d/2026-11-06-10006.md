- **Invoices: a client's figures in Edit client** (system_3 #10006, from
  #9972, operator c61586). Under "Added … · updated …", Edit client shows
  Issued invoices, Invoiced (their gross) and Last invoice (the latest issue
  date). Cancelled invoices and drafts are left out, as in the Statistics
  charts. A client with none reads "No issued invoices.", and a failed load
  says so. The fields below never move when the figures arrive.
