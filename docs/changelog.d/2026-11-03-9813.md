- Invoices: import N26 PDFs (system_3 #9760-B1). A third way in on the Payments
  tab, beside manual entry and the PayPal CSV: upload up to 10 N26 transfer
  confirmations or account statements, check each payment read from them, and
  import only the ones you keep ticked, as uncategorised payments. Rows already
  imported cannot be ticked; a row with the same date and amount as a stored
  payment starts unticked. Uses aspirant-server's `import-n26/parse` and
  `import-n26/confirm` (#9812).
