- Invoicing, Enter and Edit expense: a new category is added by typing its
  name in the Category list and choosing `Add “…”` (system_3 #11580, design
  §3.161). The name is a draft like the rest of the form: Save adds the
  category and saves the expense together, Cancel adds nothing, and a
  refused name keeps the dialog open with the reason under the field. The
  "+ Add a category" link and its own Save category form are gone. Under the
  field, a category ze added has "Remove from your categories"; a removed one
  this expense keeps has "Restore to your categories", and removing one the
  expense is not saved with puts the field back and offers `Restore “…”`
  until it changes. A starter type and Private have no action, only the line
  "To add a category, type its name in the list."
- Invoicing: a removed category is no longer offered for a new choice: not in
  the expense dialog, a Transactions row's category, Set category, or the N26
  and PayPal import reviews. An expense saved with one still shows it, and the
  Transactions filter and the Book's "Change what counts" list it while any
  expense has it.
- Invoicing, "What it was for": the device list is called suggestions. "Save
  as a category on this device" reads "Save as a suggestion on this device",
  and "Remove from this device’s categories" reads "Remove from this device’s
  suggestions". What the browser stores is unchanged, so earlier entries are
  still listed.
