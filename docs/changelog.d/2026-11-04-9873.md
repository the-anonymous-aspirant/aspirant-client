- **Invoices: set the category of several payments at once** (system_3
  #9873, from #9862). Every incoming payment has a checkbox, with a
  select-all-shown checkbox in the table header ("Select all N shown" above
  the phone cards). The selection feeds two toolbar actions. "Set category of
  N selected" writes the chosen category to every selected row. Rows the
  server refuses (for example a payment on an issued invoice) stay selected
  and are named in one alert, and the others change. "Create invoice from N
  payments" acts only when every selected row is Paid work; otherwise its
  caption says how many are not. A filter change unselects the rows it hides.
- **Invoices: PayPal Excel import.** The PayPal picker takes .xlsx as well as
  CSV ("Import PayPal CSV or Excel"). Every PayPal line names the file type,
  the summary counts payments set to Refund, and the two new skip reasons
  read "reversal (a bounce or cancellation)" and "row a reversal cancelled".
