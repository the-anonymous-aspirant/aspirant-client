- Enter expense by hand: the receipt can be attached from the start (system_3
  #11510; the operator's c70883 on #10985). The form has a "Receipt
  (optional)" control with "Attach receipt". The picked file waits in the
  browser, and Save creates the expense and then uploads the receipt to it:
  the Receipt dialog's own call and limits, only sooner. A file over 5 MB, an
  empty one, or one whose first bytes are not a PDF's, PNG's or JPEG's is
  refused at the pick. The dialog cannot be closed while Save runs with a
  file. The expense is kept whatever the upload does, and the Transactions
  summary line says which: added with its receipt, or added with the reason
  the receipt was not attached and where to add it. Editing an existing
  expense is unchanged; its receipt stays on its row.
