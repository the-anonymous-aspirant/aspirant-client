- Invoices: the client book folds by first letter (system_3 #10817, design
  §3.145). Letters run A-Z in German order, so "Ärztin" files under A and
  "Ölmann" under O, and a name that starts with a digit or a symbol files
  under "#", last. Each letter is a fold with the shared caret and a count
  ("A · 3"). All letters start folded; a book with a single letter shows it
  open. A client just saved, by hand or through "Add from payments", opens
  its letter and scrolls into view. A letter she opens stays open when the
  list reloads. On desktop, every letter's table has the same column widths,
  so the columns line up. The grouping comes from a new shared
  `listGroups.js`, which the Invoices fold (#10818) will also use.
